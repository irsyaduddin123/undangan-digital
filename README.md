💍 Undangan Digital

Aplikasi Undangan Digital berbasis Laravel yang digunakan untuk membuat dan mengelola undangan pernikahan secara online.
Aplikasi ini memiliki sistem Admin dan Customer, sehingga customer dapat membuat undangan berdasarkan template yang tersedia.
